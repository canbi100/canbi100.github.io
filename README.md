## 구성

|------|------|

## Google Search Console 등록 방법

구글 검색에 사이트가 잘 노출되려면 **Google Search Console**에 등록하는 것을 권장합니다.

1. [Google Search Console](https://search.google.com/search-console) 접속 후 로그인
2. **URL 접두사** 방식으로 `https://canbi100.github.io` 입력
3. **HTML 파일** 인증 방식 선택 → 제공되는 `google*.html` 파일을 이 저장소 루트에 추가하고 push
4. 인증 완료 후 **Sitemaps** 메뉴에서 `https://canbi100.github.io/sitemap.xml` 제출
